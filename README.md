A selective early scalper for the pump.fun paper-trading replay: it buys a young coin once for 0.05 SOL, only when the early tape looks like a genuine launch (real SOL 1–2.9, 2+ trades from 2+ distinct buyers, net buying, creator holding, creator's own buy a moderate 0.3–2.5 SOL), then exits at +15% take-profit, −8% stop-loss, a 400-slot time cap, 300 slots of staleness, or a creator sale. Tight buy/sell slippage limits reject fills that moved against it in the 2-slot latency. Paper trading only — the replay uses market data, never real funds.

## Run it

```sh
node main.ts
```
